`MultiSelectList` displays a checked or unchecked mark for each item. Your application owns selection state.

```rust
use termui_widgets::multi_select_list::MultiSelectList;

let items = [("Rust", true), ("Go", false)];
MultiSelectList::new(&items).render(frame, area);
```
