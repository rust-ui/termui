title: Button
description: Ratatui button widget with six styles, three sizes, and caller-owned focus and activation.
---

`Button` draws a terminal button. The parent app owns focus, keyboard input, and activation.

`ButtonShape::{Rectangular, Rounded}` controls the button's ends. Buttons are rectangular by default.

Use a button for one action in a form or dialog. Pair it with a [Dialog](/docs/widgets/dialog) for confirmation flows, or use a [Command Palette](/docs/widgets/command-palette) when users need to find an action from a list.

### Variants

`Button` provides `Default`, `Secondary`, `Destructive`, `Outline`, `Ghost`, and `Link` styles.

<RustDemo
  name="button-variants"
  title="Button · Variants"
  fontSize={16}
  code={`use termui_widgets::button::{Button, ButtonVariant};

Button::new("Save").variant(ButtonVariant::Default).render(frame, area);
Button::new("Cancel").variant(ButtonVariant::Secondary).render(frame, area);
Button::new("Delete").variant(ButtonVariant::Destructive).render(frame, area);
Button::new("Open").variant(ButtonVariant::Outline).render(frame, area);
Button::new("More").variant(ButtonVariant::Ghost).render(frame, area);

/>

## Usage

```rust
use termui_widgets::button::{Button, ButtonShape, ButtonVariant};

Button::new("Save")
    .variant(ButtonVariant::Default)
    .shape(ButtonShape::Rectangular)
    .focused(true)
    .render(frame, area);
```
