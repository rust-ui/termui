`KeyBar` lays out keyboard shortcuts in one line. Style keys and labels separately, then render it into a Ratatui frame area.

## Usage

```rust
use ratatui::style::{Color, Style};
use termui_widgets::key_bar::KeyBar;

KeyBar::new(vec![("q", "Quit"), ("↑↓", "Move"), ("↵", "Select")])
    .key_style(Style::default().fg(Color::Yellow))
    .label_style(Style::default().fg(Color::White))
    .render(frame, area);
```
