Build dialogs from small components. `Dialog` owns open state; `DialogTrigger` and `DialogClose` expose activation hooks; `DialogContent` draws the animated surface and returns regions for header, body, and footer children. Click the trigger in the live preview to open it.

## Components

- `Dialog` owns open state and animation timing. Call `open`, `close`, or `toggle` from your app's event handler, then call `tick` with elapsed time each frame.
- `DialogTrigger::activate(&mut dialog)` opens its parent dialog when the trigger receives activation. `DialogClose::activate(&mut dialog)` closes it.
- `DialogContent` uses `tui_overlay` for centered placement, bottom-slide animation, rounded chrome, and dim backdrop. Its `DialogAreas` let you compose content with your own Ratatui widgets.
- `DialogHeader`, `DialogTitle`, and `DialogDescription` compose the heading area. `DialogFooter` draws a separator and returns an area for action buttons.
- `dialog.close_on_outside_click(position)` closes the dialog when a click lands outside its rendered surface.

## Usage

Handle activation in the parent event loop so the dialog stays easy to compose with app-specific input and focus behavior:

```rust
if trigger_was_activated {
    trigger.activate(&mut dialog);
}
if close_button_was_activated {
    close_button.activate(&mut dialog);
}
if let Some(position) = clicked_position {
    dialog.close_on_outside_click(position);
}

dialog.tick(elapsed);
```
