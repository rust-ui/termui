Build a card with the `termui!` macro. Nested component blocks keep the structure close to RSX-style UI code while the macro renders the card into a Ratatui frame.

<RustDemo
  name="card"
  title="Card · Composable sections"
  rows={9}
  fontSize={14}
  code={`use ratatui::{layout::Rect, Frame};
use termui_widgets::termui;

fn demo_card(frame: &mut Frame<'_>, area: Rect) {
  termui! {
    frame: frame,
    area: area,
    Card {
      CardHeader {
        CardTitle { "Card Title" }
        CardDescription { "Card Description" }
      }
      CardContent { p { "Card Content" } }
      CardFooter { p { "Card Footer" } }
    }
  }
}`}
/>

## Components

- `Card` draws a rounded border and splits its inner area into header, content, and footer. Set `header_rows` and `footer_rows` to fit your content; remaining rows go to content.
- `CardHeader::layout` returns title and description areas for manual composition.
- `CardTitle` renders a bold, bright white heading. Terminal widgets cannot change font size per component.
- `CardDescription` provides muted supporting text.
- `CardContent` renders a Ratatui widget with one cell of horizontal padding by default.
- `CardFooter` draws a separator and returns a padded area for custom footer children.
- The first `termui!` macro form accepts this Card tree and literal text children. CSS classes have no terminal equivalent; use Ratatui areas and constraints to size sections.

## Usage

```rust
let areas = Card::new()
    .header_rows(2)
    .footer_rows(2)
    .render(frame, area);
let header = CardHeader::new()
    .description_rows(1)
    .layout(areas.header);

CardTitle::new("Project").render(frame, header.title);
CardDescription::new("Recent activity").render(frame, header.description);
CardContent::new(Paragraph::new("3 builds completed")).render(frame, areas.content);
let footer = CardFooter::new().render(frame, areas.footer);
frame.render_widget(Paragraph::new("Updated just now"), footer);
```
