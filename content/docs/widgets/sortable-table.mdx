title: Sortable Table
description: A table that marks its active sort column and direction.
---

`SortableTable` displays a sort marker. Your application owns sorting and row order.

## Usage

```rust
use termui_widgets::sortable_table::SortableTable;

let headers = ["Name", "Size"];
let rows: [&[&str]; 1] = [&["README.md", "2 KB"]];
SortableTable::new(&headers, &rows, 0, true).render(frame, area);
```
