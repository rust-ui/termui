Term/UI widgets are copyable Rust modules for Ratatui applications. Each component page provides its source, usage example, and Rust-rendered terminal preview.

The widgets are not distributed as a Cargo crate. Copy the module you need into your project; your application keeps ownership of its event loop and state.

Start with [installation](/docs/installation), browse the component pages below, or follow the [Ratatui form guide](/docs/guides/build-a-ratatui-form) to compose input widgets with app-owned state.
