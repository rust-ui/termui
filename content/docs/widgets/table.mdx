title: Table
description: Ratatui table widget for compact text rows with aligned headers and columns.
---

`Table` aligns text columns from the supplied header and row values.

Use it for read-only rows such as service status or a short inventory. For caller-controlled sorting indicators, see [Sortable Table](/docs/widgets/sortable-table); for a compact numeric trend, use [Sparkline](/docs/widgets/sparkline).
