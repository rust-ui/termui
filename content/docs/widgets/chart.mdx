---
title: Charts
description: Modular terminal charts for comparing, tracking, and presenting data.
---

`Chart` scales each value against the largest value in the series.

The modular chart API includes area, bar, line, pie, radar, radial, and tooltip components. Browse the [chart gallery](/charts/area) to see every rendered example and copy its Rust source from the code sheet.

<RustDemo name="chart" title="Chart" rows={7} code={`use termui_widgets::chart::Chart;

let values = [("Build", 4), ("Test", 7)];
Chart::new(&values).render(frame, area);`} />

## Source

<ComponentSource src="crates/termui-registry/src/widgets/src/chart.rs" title="chart.rs" language="rs" collapsible={false} />

## Usage

```rust
use termui_widgets::chart::Chart;

let values = [("Build", 4), ("Test", 7)];
Chart::new(&values).render(frame, area);
```
