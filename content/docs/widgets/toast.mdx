`Toast` slides in from the bottom-right over a dimmed backdrop. Call `tick` with elapsed frame time to advance its 160 ms ease-out animation, and forward mouse events to `on_mouse`; clicking **x** closes it.

## Usage

```rust
use std::time::Duration;
use termui_widgets::toast::Toast;

let mut toast = Toast::error(error);
toast.tick(Duration::from_millis(16));
toast.render(frame, area);
toast.on_mouse(mouse_event);
```
