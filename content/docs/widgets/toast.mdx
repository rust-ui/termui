---
title: Toast
description: Composable bottom-right notifications with optional dismissal and auto-dismiss progress.
---

`Toast` owns visibility, animation, and lifetime. Compose each notification from `ToastContent`, `ToastTitle`, `ToastDescription`, and optional `ToastClose` and `ToastTracker`. `ToastTrigger` exposes activation for your app's click and keyboard handlers. Toasts are dismissible by default and close automatically after five seconds.

## Default

<RustDemo
  name="toast"

  fontSize={16}
  code={`use termui_widgets::toast::{Toast, ToastClose, ToastContent, ToastDescription, ToastTitle, ToastTracker, ToastTrigger};

let mut toast = Toast::new(); // Dismissible by default; five-second lifetime.
if trigger_activated {
    ToastTrigger::new("Show toast").activate(&mut toast);
}

if let Some(areas) = ToastContent::new().render(frame, area, &mut toast) {
    ToastTitle::new("Changes saved").render(frame, areas.title);
    ToastDescription::new("Your preferences were saved successfully.")
        .render(frame, areas.description);
    if let Some(tracker) = areas.tracker {
        ToastTracker::new().render(frame, tracker, &toast);
    }
    if let Some(close) = areas.close {
        ToastClose::new().render(frame, close);
    }
}`}
/>

## Non-dismissible

Manual close control is omitted and `Toast::close()` has no effect. The configured timer still closes the toast.

<RustDemo
  name="toast-nondismissable"
  title="Toast · Non-dismissible"
  src="/demos/interactive.html?demo=toast-nondismissable-interactive"
  height={370}
  fontSize={16}
  code={`use termui_widgets::toast::{Toast, ToastContent, ToastDescription, ToastTitle, ToastTracker, ToastTrigger};

let mut toast = Toast::new().dismissible(false);
if trigger_activated {
    ToastTrigger::new("Show toast").activate(&mut toast);
}
toast.tick(elapsed);

if let Some(areas) = ToastContent::new().render(frame, area, &mut toast) {
    ToastTitle::new("Upload in progress").render(frame, areas.title);
    ToastDescription::new("This notification closes after the upload completes.")
        .render(frame, areas.description);
    if let Some(tracker) = areas.tracker {
        ToastTracker::new().render(frame, tracker, &toast);
    }
    // No ToastClose: the five-second timer still runs.
}`}
/>

## Variants

Click one of five colored triggers to show the matching notification. Keyboard keys `1`–`5` activate the same variants.

<RustDemo
  name="toast-variants"
  title="Toast · Semantic variants"
  src="/demos/interactive.html?demo=toast-variants-interactive"
  height={370}
  fontSize={16}
  code={`use ratatui::style::{Color, Style};
use termui_widgets::toast::{Toast, ToastContent, ToastTitle, ToastTracker, ToastTrigger, ToastVariant};

let mut toast = Toast::new();
if let Some((label, trigger_color)) = clicked_trigger {
    ToastTrigger::new(label)
        .style(Style::default().fg(Color::Black).bg(trigger_color))
        .activate(&mut toast);
}
toast.tick(elapsed);

if let Some((variant, title)) = active_variant {
    if let Some(areas) = ToastContent::new()
        .variant(variant)
        .render(frame, area, &mut toast)
    {
        ToastTitle::new(title).variant(variant).render(frame, areas.title);
        if let Some(tracker) = areas.tracker {
            ToastTracker::new().variant(variant).render(frame, tracker, &toast);
        }
    }
}`}
/>

## Usage

Call `tick` with elapsed frame time. `ToastAreas` includes `close` only when dismissal is enabled and `tracker` only when a timer is configured. Route unmatched left clicks to `close_on_outside_click`; it checks the rendered overlay bounds and does nothing for non-dismissible toasts.

```rust
use std::time::Duration;
use termui_widgets::toast::Toast;

let mut toast = Toast::new().dismissible(false).duration(Duration::ZERO);
toast.tick(elapsed);
toast.close_on_outside_click(position); // Returns false when non-dismissible.
```

Use `.duration(Duration::ZERO)` to disable auto-dismiss; the tracker is then omitted. A non-dismissible toast still expires when its configured timer reaches zero.
