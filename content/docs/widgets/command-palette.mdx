---
title: Command Palette
description: Ratatui command palette widget for displaying filtered actions and a selected result.
---

`CommandPalette` presents a query and command results. Your application owns filtering, selection, and activation.

Use it to expose app-wide actions such as opening a file or changing a setting. Pass the matching commands and selected index from your app; use [Search Input](/docs/widgets/search-input) for query display alone or [Select List](/docs/widgets/select-list) for a general selectable list.

## Usage

```rust
use termui_widgets::command_palette::CommandPalette;

let commands = ["Open file", "Toggle theme", "Quit"];
```
