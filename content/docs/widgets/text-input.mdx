`TextInput` draws a single-line field with a label and optional placeholder. Your app owns the value, focus, and key handling.

<RustDemo
  name="text-input"
  title="Text Input · Interactive Ratatui"
  src="/demos/interactive.html?demo=text-input-interactive"
  height={370}
  fontSize={16}
  code={`use termui_widgets::text_input::TextInput;

TextInput::new("Email")
    .value("ada@example.com")
    .focused(true)
    .render(frame, area);`}
/>

Click a field, then type. Press **Tab** to switch fields and **Backspace** to delete.

## Usage

```rust
use termui_widgets::text_input::TextInput;

TextInput::new("Workspace")
    .placeholder("Choose a name")
    .render(frame, area);
```
