`TextInput` draws a single-line field with a label and optional placeholder. Your app owns the value, focus, and key handling.

    .focused(true)
    .render(frame, area);`}

## Usage

```rust
use termui_widgets::text_input::TextInput;

TextInput::new("Workspace")
    .placeholder("Choose a name")
    .render(frame, area);
```
