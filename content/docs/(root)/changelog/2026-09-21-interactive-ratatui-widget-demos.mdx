We added keyboard-driven Ratzilla demos for 33 Ratatui widgets, covering navigation, pickers, input controls, tables, text views, charts, and overlays.

Each demo keeps its own Rust binary and checked-in WebAssembly assets. A shared HTML page and asset manifest load the selected demo.

Buttons support rounded or rectangular ends. Cards support rounded or square corners.
