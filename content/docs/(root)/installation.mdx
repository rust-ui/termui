## Prerequisites

Install Rust and Cargo with [rustup](https://rustup.rs/).

## Render a Component

Term/UI's preview frames are generated by its Rust renderer:

```bash
cargo run -p termui-renderer -- spinner
```

Choose a different component by name:

```bash
cargo run -p termui-renderer -- button
```

The website renders the generated frame data. It does not run Ink, OpenTUI, or a terminal runtime in the browser.

## Use the Rust Source

Component pages provide Rust source for copying into your application. Add Ratatui and a terminal backend to your project:

```bash
cargo add ratatui crossterm
```

Each example exposes a `render(frame, area)` function that you can adapt in your own application.

## Preview Themes

Choose a theme from the preview controls. Theme selection changes terminal colors and needs no audio dependency.
