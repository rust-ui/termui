## Prerequisites

Install Rust and Cargo with [rustup](https://rustup.rs/).

## Render a Component

Term/UI's preview frames are generated by its Rust renderer:

```bash
cargo run -p termui-renderer -- spinner
```

Choose a different component by name:

```bash
cargo run -p termui-renderer -- button
```

The website renders generated Rust frame data. Interactive demos use Rust and WebAssembly only where user input changes widget state.

## Use the Rust Source

Term/UI widgets are source modules, not a published crate. Copy the Rust source from a component page into your application, then add Ratatui and a terminal backend:

```bash
cargo add ratatui crossterm
```

Each example shows the widget's render call. Adapt its import path to your app's module tree. Some composed widgets use sibling Term/UI modules; copy those dependencies too and preserve or update their `crate::` imports. Your app owns the event loop, state, and input handling.

## Preview Themes

Choose a theme from the preview controls. Theme selection changes terminal colors and needs no audio dependency.
