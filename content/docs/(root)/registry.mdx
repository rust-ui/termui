title: Registry
description: Learn how to use the Term/UI registry with the shadcn CLI.
---

The **Term/UI** registry ships Ink and OpenTUI components, hooks, providers, and themes in the [shadcn registry format](https://ui.shadcn.com/docs/registry). Register the namespace once in `components.json`, then pull items by name with the CLI.

## Setup

Add a **registries** entry for this site. See the [shadcn registry documentation](https://ui.shadcn.com/docs/registry) for all `components.json` fields and behaviors.

```json
{
  "registries": {
    "@termui": "https://rust-ui.com/r/{name}.json"
  }
}
```

You can replace `@termui` with another namespace; it only needs to match what you pass to `shadcn add`.

## Usage

Items are namespaced by base: `ink/` for Ink and `opentui/` for OpenTUI.

Registry files follow these destinations:

- Components install into `components/ui/`.
- Hooks install into the configured `hooks/` directory.
- Theme, motion, and Unicode providers install into `providers/`.
- Themes install into `lib/terminal-themes/`.

Components declare their hook dependencies, so installing a component does not install or require a provider.

### Ink

Install a component:

```bash
npx shadcn@latest add @termui/ink/spinner
```

Install a theme:

```bash
npx shadcn@latest add @termui/ink/theme-dracula
```

Install the theme provider:

```bash
npx shadcn@latest add @termui/ink/theme-provider
```

Install the motion provider:

```bash
npx shadcn@latest add @termui/ink/motion-provider
```

Install the unicode provider:

```bash
npx shadcn@latest add @termui/ink/unicode-provider
```

Without a registry alias, use the full URL (as on each docs page):

```bash
npx shadcn@latest add https://rust-ui.com/r/ink/spinner.json
```
