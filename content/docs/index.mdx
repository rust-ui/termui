description: Copyable Rust components for Ratatui terminal applications, with source code and Rust-rendered previews.
---

Term/UI is a collection of copyable Rust widgets for Ratatui terminal applications. Each component page includes source, usage, and a terminal preview.

The website generates static preview frames at build time with a native Rust renderer. Interactive WebAssembly demos are used only where input meaningfully changes widget state.

The components are not published as a crate. Copy the Rust source from each page into your app; your application owns its event loop and state.

Browse the [Ratatui widgets](/docs/widgets) or follow the [installation guide](/docs/installation) to start building with copyable inputs.
