---
title: Introduction
description: Rust terminal UI components with static previews rendered from Rust output.
---

TERMUI is a collection of copyable terminal UI components for Rust applications.

The website generates preview frames at build time with a native Rust renderer. Browser pages display those frames as text; no terminal runtime or WebAssembly renderer runs in the browser.

Components are not published as a crate. Copy the Rust source from each component page into your application and adapt it to your needs.
