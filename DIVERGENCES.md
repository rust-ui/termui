# Differences from termcn

TERMUI keeps termcn’s website UI and non-Sponsor routes. These implementation differences are intentional:

- Demo frames are generated by `crates/termui-renderer` at build time and displayed by the existing React preview components. They are static Rust output, not live Rust execution in the browser.
- Ratzilla demos and generated WASM bundles are removed. The website has no Ratzilla or Ratatui runtime dependency.
- Sound playback is disabled. Theme and sound controls keep their termcn appearance and state behavior.
- The Sponsor page and its links/SEO entries are omitted.
- Site identity, GitHub destination, and Rust-specific product descriptions are changed to TERMUI.
- Ink/OpenTUI docs, registry assets, and page variants remain to preserve termcn’s full information architecture and UI. Their component/source snippets may still describe those ecosystems; TERMUI previews are rendered by Rust.

Any additional difference required for the Rust renderer or unavailable external service should be added here with its file and reason.
